# Legacy Trap: The 1945 Architecture vs. 2026 AI Game

A viral-style browser game demonstrating why modern autonomous AI cannot safely rely on 1945 von Neumann architecture and software-only guardrails.

## The Concept
Modern autonomous AI systems act with high-consequence real-world agency, but they run on legacy computing foundations that lack intrinsic isolation. When software guardrails try to police themselves within the same memory space, it creates a **circular dependency** prone to drift and compromise.

This game puts the player in control of an AI core navigating through legacy hardware bottlenecks, software bugs, and the circular dependency trap.

## Features
* Fast-paced arcade mechanics built in pure HTML5/JavaScript.
* Zero dependencies—runs instantly in any browser.
* Mobile and desktop friendly (touch and arrow key controls).

## Local Development
To run locally, simply clone or download this repository, save the file as `index.html`, and open it in any web browser.
